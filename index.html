دليل النشر والتعديل على GitHub Pages

🚀 كيفية رفع المشروع على GitHub Pages:

  1. قم بإنشاء مستودع جديد (Repository) باسم khadamatk-demo على GitHub.
  2. ارفع ملف index.html مباشرة في الجذر الرئيسي (Root Directory).
  3. انتقل إلى Settings ➔ Pages في مستودع GitHub.
  4. في قسم Source، اختر فرع main والمجلد / (root) ثم اضغط Save.
  5. سيصبح موقع التطبيق التفاعلي المباشر متوفراً خلال ثوانٍ عبر الرابط المخصص!
💡 مميزات المشروع: خفيف الوزن، لا يحتاج سيرفر أو Node.js، يعتمد على Vanilla JavaScript وCSS مخصص للغة العربية RTL.
